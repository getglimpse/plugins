# File Converter

Sample plugin for converting dropped text and Markdown files from a Glimpse Internal Page.

Features:

- `Converter` tab instead of `Playground`
- drag-and-drop or file picker input
- `.txt`, `.md`, and `.markdown` files
- conversion adds `Success Converted!` to the top of the input file
- configurable output directory in the Settings tab
- output directory text input with a directory opener button

Install from **Plugin Page** by selecting this directory, then trust and enable
the plugin.
