# Glimpse Plugin Templates

These templates are small, installable v0.2.0 plugin folders. They are meant to
be copied before editing, but each template can also be installed directly from
Plugin Page for a quick smoke test.

## Pick a Template

| Template | Start here when you want to... |
| --- | --- |
| `basic-action-template-plugin` | run a text action from a standard Playground tab. |
| `file-converter-template-plugin` | accept dropped files and write converted output files. |
| `file-viewer-template-plugin` | preview files with a plugin viewer contribution. |

Each template includes its own README:

- [Basic action template](./basic-action-template-plugin/README.md)
- [File converter template](./file-converter-template-plugin/README.md)
- [File viewer template](./file-viewer-template-plugin/README.md)

## Common File Layout

```text
template-plugin/
|-- manifest.json  plugin metadata, capabilities, settings, contributions
|-- page.json      standard page tab declarations
|-- main.js        action, viewer, and lifecycle logic
|-- i18n.json      optional strings, loaded because manifest.json links it
`-- styles.css     optional scoped styles, only used by the viewer template
```

Settings and Info tabs are generated by Glimpse. Do not add `settings` or
`info` tabs to `page.json`.

## Copy Checklist

1. Copy one template directory to a new plugin folder.
2. Rename the folder to the final plugin id, for example `my-notes-plugin`.
3. Update `manifest.json`:
   - `id`
   - `name`
   - `description`
   - `contributes.internalPage.id`
   - `contributes.internalPage.titleFallback`
   - aliases, actions, viewers, settings, and capabilities as needed
4. Update `page.json`:
   - top-level `id`
   - tab `action` references
   - labels and fallback text
5. Update `main.js`:
   - registered action or viewer ids
   - plugin-specific logic
   - log messages that contain the template plugin id
6. Update `i18n.json` or remove `manifest.i18n` if localized strings are not needed.

`manifest.id`, the plugin folder name, `contributes.internalPage.id`, and
`page.json` `id` must agree:

```text
folder: my-notes-plugin
manifest.id: my-notes-plugin
contributes.internalPage.id: plugin:my-notes-plugin
page.json id: plugin:my-notes-plugin
```

## Local Smoke Test

1. Open Plugin Page in Glimpse.
2. Enter the absolute path to the copied plugin directory.
3. Install the plugin.
4. Trust the plugin.
5. Turn the plugin on.
6. Open the plugin page from Internal search, or open a file that matches a viewer template.

Installing or replacing a plugin clears its trust record. That is expected while
iterating on template-derived plugins.
