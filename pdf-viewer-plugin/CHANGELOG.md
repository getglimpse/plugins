# Changelog

## 0.1.0 - 2026-07-28

- Added the PDF viewer plugin.
- Added `contributes.viewers` metadata for `.pdf`.
- Added plugin-owned PDF preview rendering in `main.js`.
- Converted local file paths through `ctx.files.toAssetUrl()`.
- Switched to iframe-based PDF rendering.
- Added `page.js` overview page for the viewer plugin.
- Added `manifest.i18n` metadata.
- Added plugin-scoped `styles.css`.
